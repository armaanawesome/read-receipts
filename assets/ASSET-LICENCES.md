# Asset provenance

Where every shipped asset came from, and what licence it carries.

This exists so the question "can you prove you are allowed to ship that?" has an
answer other than "probably". The burden of proving a licence falls on whoever
distributes the file, and a takedown does not wait while you go looking. See
docs/LEGAL-REVIEW.md, Count 9.

Anything marked **UNKNOWN** is a gap, not a verdict. Fill it or replace the file
before a store release.

## Audio — 22 files, all synthesised in this repo

**Licence: none needed. No third-party rights attached.**

Every `.wav` in `assets/audio/` is generated by `tools/make-audio.mjs`, which is
in this repository and under the MIT licence with the rest of the code. Nothing
was sampled, downloaded or licensed from anyone.

That was a deliberate call, and the generator says so in its own opening
comment — the reasoning was that a competition entry needs every asset clearly
licensed, and generated sound is a stronger position than "the licence page said
CC0 in September". It also makes the cues reproducible: change the file, run it
again.

```bash
node tools/make-audio.mjs
```

| Files | Source | Licence |
|---|---|---|
| `audio/*.wav` (5 cues, 17 beds) | `tools/make-audio.mjs` in this repo | Own work, MIT with the code |

To prove it, delete the directory and re-run the generator. The files come back.

### What has to be checked about the covers

Sixteen covers were produced across two tools over several sessions. Before a
store release, record for each one which tool made it, because the terms differ
and two constraints actually bite:

1. **Stock elements cannot be used standalone.** Canva's licence lets you use a
   *design* commercially, including one built from their stock content. It does
   not let you ship a stock photo or graphic on its own as though it were yours.
   A cover that is essentially one licensed element with a title over it sits
   closer to that line than a composed design does.
2. **AI-generated images are hard to own.** In the US, the UK and most of the
   EU, an image generated from a text prompt with no meaningful human authorship
   attracts thin copyright or none. Practically: you can ship these, and you
   cannot stop somebody else generating something similar. Do not build a
   trade-mark application on one.

Neither is a reason to change anything today. Both are reasons to write down
which tool made which file while it is still possible to remember.

## Keeping this true

Add a row when you add a file. An asset that arrives without a row is an asset
nobody can defend later — and the person who has to defend it is usually not the
person who added it.
